Slot Coordination & Management

L4 Step Detail

StepL4 Step NameRoleSystem InputOutputKPI Pain Point / RiskDecisionException
1.1 Analyse seasonal schedule demand vs slot inventory Network Planning Analyst Amadeus SkyCAST Approved seasonal schedule build, prior-season slot inventory Slot gap analysis report identifying constrained O&D pairs Slot gap identification rate ≥95% before coordinator submission deadline SkyCAST demand forecasts do not auto-reconcile with live coordinator slot libraries — manual cross-check required, introducing errors in high-frequency bank builds
1.2 Classify constrained airports by IATA Level 2 / Level 3 Slot Coordinator OAG Schedule Analyser Slot gap analysis report, OAG airport level classification data Constrained airport register with Level 2/3 designation and coordinator contact 100% of Level 3 airports correctly classified before coordinator submission window opens IATA airport level classification updates lag real-world congestion changes by up to one season; misclassification causes incorrect submission routing and missed deadlines ✓
1.3 Generate prioritised slot request register Slot Coordinator Amadeus SkyWORKS Constrained airport register, route profitability data from SkyCAST Prioritised slot request register ranked by revenue impact Slot requests submitted ≥8 weeks before IATA coordination deadline Late submission forfeits priority queue position at 47% of Level 3 coordinators; SkyWORKS has no built-in deadline tracking for each coordinator's unique submission calendar
2.1 Extract historical slot series from IATA CRS portal Slot Coordinator IATA CRS (Coordinated Reservation System) Prior-season SSIM files, coordinator portal access credentials Historical slot series inventory per airport with series reference codes 100% of historical series extracted before coordinator portal submission window closes IATA CRS portal availability falls below 99.5% during peak submission windows; fallback is manual email-based SSIM exchange with no automated validation
2.2 Validate 80/20 utilisation rule compliance per series Slot Compliance Analyst Amadeus SkyWORKS Historical slot series inventory, actual operations data from prior season Series compliance report with used/available ratio per airport per series Grandfather right retention rate ≥98% of eligible series per IATA WSG Operational disruptions (weather, ATC) erode utilisation ratios; airlines must file force majeure exemptions within 5 days of each triggering event — SkyWORKS does not auto-flag breaches in real time ✓ ✓
2.3 File force majeure exemptions for at-risk series Slot Coordinator IATA CRS (Coordinated Reservation System) Series compliance report, confirmed disruption log with ATC/weather evidence Accepted exemption filing per affected slot series Exemption filed within 5 calendar days of triggering disruption event Missed exemption window results in permanent series loss with no appeals mechanism at most Level 3 airports; coordinator acceptance rates vary by region (EU coordinators accept ~82%, US FAA exempt) ✓
3.1 Generate SSIM-formatted SCR slot request messages Slot Coordinator Amadeus SkyWORKS Prioritised slot request register, validated historical series inventory SSIM SCR message set ready for coordinator submission SSIM file validation error rate < 1% on first submission SkyWORKS SSIM export requires manual field mapping for airports not in the standard IATA airport list; common source of format errors that delay acceptance by coordinator systems
3.2 Submit slot requests to each airport coordinator Slot Coordinator IATA CRS (Coordinated Reservation System) SSIM SCR message set, coordinator portal credentials per airport Submitted SCR messages with coordinator receipt confirmations 100% of requests submitted before each coordinator's unique deadline Airport coordinators (ACNUSA, NATS, DFS, FAA, etc.) each operate different portal UIs with no single API standard; multi-airport submissions require manual portal navigation per coordinator
3.3 Evaluate initial slot allocation vs requested schedule Network Planning Analyst OAG Schedule Analyser Coordinator SCT (slot confirmation) messages, original slot request register Allocation gap report identifying unmatched or partially matched requests Allocation match rate ≥85% of requested slots in initial SCT response Coordinators allocate on grandfather-then-new-entrant priority; late filers receive only residual slots, which are frequently at off-peak times incompatible with planned bank structures ✓
4.1 Prepare negotiation brief for IATA slot conference Senior Network Planner Amadeus SkySYM Allocation gap report, network simulation scenarios from SkySYM Negotiation brief with ranked alternative slot windows and revenue impact estimates Brief finalised ≥2 weeks before IATA slot conference opening date SkySYM scenario export does not auto-generate slot swap proposals; analyst must manually map network simulation outputs to coordinator slot pool data, taking 3–5 days per conference cycle
4.2 Negotiate slot swaps and alternatives at conference VP Network Planning IATA CRS (Coordinated Reservation System) Negotiation brief, coordinator available slot pool published at conference Agreed slot swaps or confirmed alternative allocations ≥70% of critical slot gaps (top 10 revenue routes) resolved at conference Bilateral swap negotiations are blocked when the counterparty airline holds conflicting grandfather claims on the same series; coordinator cannot force swaps without both parties' consent under IATA WSG §9 ✓ ✓
4.3 File appeal for unresolved critical slot gaps Slot Coordinator IATA CRS (Coordinated Reservation System) Unresolved slot gap list post-conference, coordinator appeal process documentation Formal appeal filing or coordinator mediation request Appeal response received within 5 business days of filing Appeal panels have no binding authority at most coordinators; outcomes are advisory only, leaving airlines with no recourse if coordinator declines to intervene in grandfather disputes ✓
5.1 Confirm final slot allocation and accept coordinator offer Slot Coordinator IATA CRS (Coordinated Reservation System) Final SCT messages from all coordinators including post-conference revisions Accepted slot confirmation records per airport per series 100% of confirmed slots acknowledged within 24h of coordinator receipt Coordinator systems deliver SCT messages in overnight batch files; missed or delayed messages require manual reconciliation with coordinator helpdesk, often taking 2–3 business days to resolve
5.2 Integrate confirmed slots into SkyWORKS schedule build Network Planning Analyst Amadeus SkyWORKS Accepted slot confirmation records, current SkyWORKS seasonal schedule Updated SkyWORKS schedule with slot-validated departure and arrival times per flight leg Schedule-to-slot reconciliation accuracy ≥99.5% before SSIM publication Slot times and SkyWORKS schedule times drift due to timezone and DST mapping errors during SSIM import; DST boundary airports (e.g. LORD, EIDW) are a recurring source of off-by-one-hour faults ✓ ✓
5.3 Publish season SSIM file to GDS channels and PSS Slot Coordinator Amadeus SkyWORKS Slot-validated SkyWORKS schedule Published SSIM file distributed to Sabre GDS, Travelport GDS, Amadeus GDS, and Amadeus Altéa PSS SSIM distributed to all GDS ≤72h after final coordinator confirmation GDS distribution from SkyWORKS is fire-and-forget with no real-time ACK; distribution failures are silent and only detected when downstream booking discrepancies surface 24–48h later ✓
6.1 Monitor weekly slot utilisation against 80% threshold Slot Compliance Analyst Amadeus SkyWORKS Weekly actual operations data, slot series inventory with coordinator reference codes Weekly slot utilisation compliance report per series per airport Slot series utilisation ≥80% per IATA WSG standard throughout season Operational cancellations and schedule swaps erode utilisation without triggering automated alerts in SkyWORKS; compliance analysts must run manual SQL queries against ops data to compute rolling utilisation ratios ✓
6.2 Return or swap underperforming slot series Slot Coordinator IATA CRS (Coordinated Reservation System) Utilisation compliance report identifying series below 80%, coordinator return deadlines Slot return confirmations or approved swap records per series Slot returns submitted ≥48h before departure per IATA WSG in-season return deadline Late returns are forfeited to the slot pool with no recovery; repeated late-return flags accumulate as coordinator penalty records that reduce priority scoring in subsequent season bids
6.3 Execute ad-hoc slot swaps for operational recovery Slot Coordinator IATA CRS (Coordinated Reservation System) Operations disruption report, coordinator available slot pool for swap Ad-hoc swap confirmation and updated slot record in SkyWORKS Ad-hoc swap processed within 2h of disruption notification during coordinator office hours Coordinator swap availability is limited to office hours (typically 07:00–19:00 local); out-of-hours disruptions at Level 3 airports have no swap mechanism, forcing cancellation or slot violation ✓
