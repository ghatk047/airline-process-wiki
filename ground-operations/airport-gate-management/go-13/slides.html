StepL4 Step Name KPI / TargetPain Point / RiskGate
1.1 Pull TSA Security Directive updates from portal Directive review completion 100% by 04:00 local; zero missed directives TSA directives arrive with minimal lead time and no automated push — coordinator must manually poll the portal daily; late directives received after briefings require real-time re-briefing of ramp and gate teams
1.2 Configure Secure Flight data elements in PSS Secure Flight data completeness ≥99.5% of PNRs before check-in window opens Missing Secure Flight data from OTA and indirect bookings (name misspellings, missing DOB) requires last-minute PNR remediation calls to passengers — average 4–6 incidents per hub departure bank
1.3 Verify Airport Security Program compliance readiness ASP readiness sign-off ≥60 min before first departure; 100% rostered security staff TSA-certified High turnover at outstations leads to uncertified agents being inadvertently rostered in AOA access roles — TSA civil penalties up to $25,000 per violation; AMS roster does not flag certification expiry automatically
2.1 Transmit Secure Flight Passenger Data Records to TSA Transmission ≥72 hours before departure for advance bookings; 100% transmitted before check-in opens for same-day bookings Altéa Secure Flight module timeout during high-volume morning bank causes batch retransmission queues; TSA SLA requires 2-min response window — backlog during irregular operations extends to 15+ min, blocking boarding pass issuance
2.2 Receive Boarding Pass Print Result from TSA BPPR response received within 2 min per passenger; 100% BPPR statuses resolved before check-in closes TSA BPPR 'Inhibited' status returned without explanation — agent must call TSA help desk with average hold time of 8–12 min; no case tracking integration between Altéa and TSA portal causes duplicate escalation calls ⚠
2.3 Escalate SSSS or No-Fly result to TSA liaison SSSS coordination completed ≥45 min before departure; no-fly offload confirmed ≥30 min before departure; 100% SSSS passengers cleared or offloaded before gate close Redress number mismatches cause false positives for passengers with common names — average 3–4 false positives per week at major hubs; each requires DHS TRIP form initiation and manual TSA override, averaging 20 min per incident
3.1 Verify passenger identity document at gate Gate document check throughput <45 sec per passenger; REAL ID non-compliance interception rate 100%; boarding completion ≥10 min before departure No automated integration between AMS ID scanner and Altéa PNR — agent must manually annotate non-compliance; inconsistent REAL ID passenger awareness creates gate-queue backlog averaging 4 min per non-compliant incident ⚠
3.2 Handle REAL ID non-compliance exception at gate REAL ID exception resolution <5 min; denied boarding documented in Altéa within 15 min of incident; zero passengers boarded without TSA-acceptable ID No automated link between AMS gate scanner and Altéa PNR creates audit gaps flagged in TSA compliance inspections; manual annotation relies on agent recall during high-throughput boarding — data quality degrades under pressure
4.1 Submit hold baggage manifest to TSA EDS screening 100% of hold bags submitted to EDS before ramp loading begins; EDS screening throughput ≥300 bags/hr at Level 1 EDS machine downtime averages 4.2 hr/month per unit at busy stations; fallback to manual ETD screening reduces throughput by 60% and directly risks D0 departure delay — no automated EDS status feed into BagManager to trigger backup protocol
4.2 Execute passenger-baggage reconciliation check Reconciliation completed ≥15 min before scheduled departure; mismatched bag rate <0.1% of loaded bags Interline baggage transfers lack real-time status in BagManager — connecting bags from partner carriers are invisible to reconciliation logic; increases unaccompanied bag risk on multi-carrier itineraries handled at shared terminals ⚠
4.3 Remove and re-screen unaccompanied baggage Unaccompanied bag off-load completed <10 min of identification; zero unaccompanied bags loaded; off-load documented 100% in BagManager Off-loading a reconciliation-mismatched bag from a loaded aircraft requires full ramp access re-coordination with TSA and averages 18-min departure delay — each incident costs approximately $8,400 in direct delay costs and downstream slot penalties at coordinated airports
5.1 Transmit eAPIS passenger manifest to CBP Manifest transmitted ≥60 min before international departure per 19 CFR 122.49a; 100% transmission rate; CBP acknowledgement within 10 min Passport data OCR errors from self-service kiosks and online check-in produce CBP manifest rejections — average 2.3 passport corrections per international flight; each manual correction and CBP resubmission adds 8–10 min to pre-departure workload
5.2 Receive and action CBP pre-departure APIS response CBP no-board response processed ≤10 min of receipt; 100% no-board orders actioned before gate close CBP no-board orders occasionally arrive after gate close due to APIS processing latency — requires aircraft door reopening and coordinated offload, averaging 25-min delay and possible slot forfeiture at slot-controlled international airports (JFK, LGA, DCA, ORD) ⚠
5.3 Offload CBP no-board passenger and associated bags No-board offload completed <15 min of order receipt; 100% associated baggage removed before departure; CBP case number documented in PNR Multi-segment bookings with interline bag transfers make associated baggage identification time-consuming — BagManager search limited to locally scanned bags; bags transferred from partner carriers on feeder flights are invisible, risking incomplete removal and TSA violation
6.1 Report security incident to TSA Operations Center Initial report filed within 4 hours of occurrence per 49 CFR Part 1544.305; 100% incident capture with zero unreported events TSA eFile portal has no mobile interface — field agents must return to operations counter to file reports; creates reporting delays during concurrent gate incidents and documentation gaps when multiple events occur simultaneously across a departure bank
6.2 Conduct post-departure security compliance audit Audit report completed within 2 hours of last departure; security exception rate <1% of daily passengers processed; 100% exceptions assigned corrective owner No unified compliance dashboard — AMS gate logs, Altéa BPPR records, and BagManager reconciliation data must be manually cross-referenced; average 45 min/day of manual report assembly per station; data format inconsistencies between systems cause reconciliation errors flagged in TSA programmatic inspections ⚠
