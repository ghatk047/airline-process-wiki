Airline-Specific Risks & Pain Points

Last-minute aircraft swaps (e.g., 737-800 replaced by 737-700) cause DOW discrepancy if AMOS weight record not updated within 30 min of tail reassignment
Manual re-entry required when API link between Lido/Flight and SITA LoadManager is unavailable; transcription errors produce erroneous TOW calculations
MZFW and MTOW vary by 737 sub-variant (e.g., 737-800 vs 737-8 MAX); incorrect variant code in LoadManager causes structural limit overrun risk without automated alert
Late check-in waivers granted after cutoff add PAX to Altéa without auto-alerting load controller; controller may issue load sheet based on stale PAX count
Incorrect season flag (summer/winter) in SITA LoadManager causes systematic 4 kg/PAX under-estimate on narrow-body routes with no automated audit trail for season changes
Individual baggage weighting not performed on narrow-body short-haul; weight estimated from PAX count × standard bag weight, resulting in actual vs plan variance exceeding 200 kg on full flights
